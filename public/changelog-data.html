v1.2.0

October 18, 2026
Other
  • Log secret creation request source Classify requests as extension, web, or unknown based on their Origin header and include the source in secret creation logs.
  • Move Beszel hub off its default port Publish the hub on localhost port 58988 instead of 8090 to avoid default-port scans, keeping the container's internal port unchanged. Update the agent URL, example environment, and setup and reverse-proxy documentation to match.
  • Add Beszel monitoring stack and deployment Add a separate Beszel hub and agent Compose stack, document its setup and updates, and provide a manual GitHub Actions workflow to deploy it independently of the Blink app.
  • Add structured logging with pino, end to end Replaces morgan/console.* with pino: every significant action (secret created/viewed/destroyed, OTP sent/verified, license activate/deactivate, OAuth login, rate limits, tampered sessions, misconfiguration) logs to both the console and a rotating file under LOGS_DIR (daily, gzip, 14-day retention) so nothing is lost across a container restart. Access logging is scoped to /api/* only, so static assets and page loads don't produce a line per file on every page view, while errors always log regardless of path. Logged IP uses Express's trust-proxy-aware req.ip instead of pino-http's default raw-socket address, which behind a reverse proxy would otherwise be identical for every visitor. flushLogs() is awaited before every intentional process.exit() (shutdown, uncaughtException, unhandledRejection), since exiting right after a burst of writes can otherwise lose them outright - verified by reproducing the loss and then the fix with a real write-then-exit test. Secrets, keys, OTP codes, and passphrases never reach a log line: call sites only ever log specific chosen fields, backed by pino's redact config. Also fixes two gaps left over from the GitHub sign-in work: missing GITHUB_CLIENT_ID/SECRET/REDIRECT_URI in docker-compose.yml, and enables the no-console ESLint rule so this can't silently regress.
  • Add GitHub sign-in for Pro accounts Support GitHub OAuth alongside Google, using verified email to share Pro accounts across providers and migrate existing license mappings. Update sign-in and privacy copy, and restrict service worker interception to same-origin requests with an offline cache fallback.
  • Update style.css
  • Add segmented OTP code input Replace the single verification-code field with six digit boxes that support auto-advance, paste, autofill, and keyboard navigation. Adjust the Blink logo dimensions in email headers.
  • Update about.html
  • Document the Blink browser extension Add extension features, store availability, architecture, and setup details to the README, and add a browser extension FAQ to the About page.
